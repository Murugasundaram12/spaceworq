# SPACEWORQ – Pending Business Decisions

This document lists all business policies that intentionally avoid hardcoded assumptions in the backend. Each setting is configurable via the `system_settings` database table (or corresponding `.env` / `config/spaceworq.php` keys) and operates conservatively / fails closed until approved by stakeholders.

| Setting Key / Area | Config / `system_settings` Key | Current Conservative Default | Observed Reference Hint (Unapproved for Hardcoding) | Impact & Recommended Action |
|---|---|---|---|---|
| **1. Payment Gateway Credentials** | `RAZORPAY_KEY_ID`, `RAZORPAY_KEY_SECRET`, `RAZORPAY_WEBHOOK_SECRET` | Unconfigured (`null`) -> Payment initiation/verification fails closed with HTTP `503` | Official site references live online payment flow | Provision Razorpay sandbox/production keys and webhook secret in `.env` before enabling checkout. |
| **2. Platform Default Tax / GST Rate** | `system_settings.key = default_tax_rate` / `SPACEWORQ_DEFAULT_TAX_RATE` | `null` (applies `0%` unless workspace sets `gst_enabled = true` and `tax_rate`) | `spaceworq-clone/js/main.js` uses `18%`; vendor workspace modal defaults GST rate field to `18` | Confirm whether `18%` GST applies globally when a workspace enables GST without specifying `tax_rate`, or per HSN/service category. |
| **3. Unpaid Booking Hold Duration** | `system_settings.key = booking_hold_minutes` / `SPACEWORQ_BOOKING_HOLD_MINUTES` | `null` (no automatic hold expiration timestamp unless configured) | Common checkout holds are 10–15 minutes | Set approved hold duration (e.g., `15`) and schedule an artisan command to release expired unpaid bookings. |
| **4. Half-Day Pricing Multiplier** | `system_settings.key = half_day_multiplier` / `SPACEWORQ_HALF_DAY_MULTIPLIER` | `null` (requires workspace `price_per_half_day` or fails `422` for `morning`/`afternoon` slots until configured) | `spaceworq-clone/js/main.js` uses `0.65` of daily price | Confirm whether `morning`/`afternoon` slots should use explicit `price_per_half_day` per workspace or fallback `0.65 * price_per_day`. |
| **5. Maximum Instant Booking Seats** | `system_settings.key = max_instant_booking_seats` / `SPACEWORQ_MAX_INSTANT_SEATS` | `null` (capped only by `workspace_listing_configs.max_seats` and `workspace.available_seats`) | `spaceworq-clone` routes >25 seats to Enterprise Consultation | Confirm platform-wide maximum online instant booking cap (e.g., `25`). |
| **6. Free Cancellation Cutoff Hours** | `system_settings.key = cancellation_cutoff_hours` / `SPACEWORQ_CANCELLATION_CUTOFF_HOURS` | `null` (`refundable_amount = 0.00` recorded until cutoff policy is configured) | Official FAQ mentions full refund when cancelled 2+ hours before start time | Confirm cutoff window (e.g., `2` hours) and cancellation fee rules before automating gateway refunds. |
| **7. Pay at Venue Option** | `system_settings.key = pay_at_venue_enabled` / `SPACEWORQ_PAY_AT_VENUE_ENABLED` | `false` (online payment required) | Not enabled on verified instant checkout | Keep disabled unless offline/pay-at-desk booking workflow is approved. |
| **8. Non-Day-Pass Instant Booking** | `system_settings.key = allow_non_day_pass_instant_book` / `SPACEWORQ_ALLOW_NON_DAY_PASS_INSTANT` | `false` (`DAY_PASS` and `MEETINGS_EVENTS` allow instant booking; Long-Term Leasing / Virtual Office route to Reserve Requests) | Matches verified `spaceworq-clone` and `spaceworq.com` separation | Confirm if individual coworking/virtual-office subcategories can opt in to instant booking via `is_instant_bookable`. |
| **9. Dynamic Coupon Catalog** | `coupons` DB table (`Admin -> Coupons`) | `0` coupons seeded | `WORQ10` / `FIRSTWORQ` appeared in static demo JS (`js/main.js`) | Business team creates approved coupons dynamically via `/api/v1/admin/coupons` with validity dates, category scope, and per-user caps. |
| **10. Frontend Integration Binding** | `spaceworq-clone/` & Vendor HTML/JS files | Unmodified (exact Phase 0 SHA-256 baseline preserved) | Separate phase outside backend-only scope | Approve frontend wiring task separately to connect existing HTML/JS `fetch()` calls to `/api/v1/*` endpoints. |
